# Players First MVP

A lightweight Vercel-ready Next.js MVP for a community action generator.

## What V1 does
- Five contribution routes:
  - Send feedback to IGG
  - Post in Discord/community
  - Post publicly
  - Make a short personal video
  - Creator mode
- Personalises drafts using:
  - issue
  - tone
  - player type
  - years played
  - what the player still loves
  - personal impact
- "Give me another version" changes wording so outputs are not identical.
- No login, no database, no analytics.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Import this repository into Vercel.
2. Let Vercel detect Next.js automatically.
3. Deploy with the default framework settings.
4. Keep the project private while testing.

## Privacy / attribution checklist
If you do not want your personal name publicly associated with the project:
- Use the neutral GitHub Organization/repository identity.
- Use a project email for public contact.
- Do not put personal names in README, package metadata, site footer, domain registration, analytics, or public Vercel project metadata.
- Note: GitHub organization ownership or public activity may still reveal account links depending on privacy settings.
